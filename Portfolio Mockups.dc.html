SEO checklist

Metadata
Per-route generateMetadata, canonical URLs via metadataBase, unique 55-char titles and 150-char descriptions, alternates for hreflang if you add FR/AR.
Structured data
Person + WebSite on root, BreadcrumbList on nested routes, CreativeWork per case study, AggregateRating on the reviews section (real Upwork data only), FAQPage if you add an FAQ.
Crawl & index
Dynamic sitemap.ts with lastModified from Sanity, robots.ts allowing all and pointing at the sitemap, no orphan pages, internal links from home to every case study.
Performance budget
LCP under 1.2s, CLS 0, JS under 120kb gzipped on home. Static render everything; GSAP loaded in a client island only. next/font self-hosting, AVIF via next/image with explicit sizes.
Social
Edge OG images per route, Twitter summary_large_image, RSS at /feed.xml once writing exists.

Motion spec — GSAP

Hero
SplitText per-line mask reveal, 0.9s, stagger 0.08, power3.out. Widget floats on an infinite yoyo tween and parallaxes on scroll.
Proof numbers
ScrollTrigger-gated count-up on $14.2k / 30+ / 5.00 / 100%, once only, 1.4s. Bars wipe up with a 0.06 stagger.
Work rows
Image clip-path reveal with a slight scale-down from 1.06; copy rises 24px. Optional pinned horizontal scroll on the /work index.
Marquees
Seamless gsap.to x-loop with velocity-linked speed on scroll; pauses on hover and when offscreen.
Transitions
View Transitions API for route changes with a GSAP fallback. No smooth-scroll hijacking — it hurts both UX and crawlability.
Non-negotiables
Content renders in HTML before JS. prefers-reduced-motion kills every tween. gsap.context() cleanup in every effect.
